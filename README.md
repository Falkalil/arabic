# لغتي — الكتب التفاعلية

كتب «لغتي» التفاعلية للصفوف من الأول إلى السادس الابتدائي (الجزء الأول)، مبنية من كتب الطالب.

- الكتب: `grade1/` … `grade6/`
- تطبيقات أندرويد: `download/arabic1.apk` … `download/arabic6.apk`
- النسخ التي تعمل دون إنترنت: `download/arabic1-offline.html` …
- القراءة النموذجية بصوت «حامد»: شغّل `python tools/gen_audio.py` من مجلد الصف.

تصميم: أ. فهد الشيخي
