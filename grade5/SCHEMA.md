# مخطّط بيانات كتاب لغتي الجميلة (الصف الخامس، الجزء الأول)

كل وحدة ملف ES module في `lessons/js/units/uN.js` يصدّر أربعة أشياء:

```js
export const UNIT = { n: 2, t: 'الوحدة الثانية: ربوعٌ من بلادي', c: '#2a9d9b', p: [54, 93], items: ['u2in', 'u2d1', 'u2d2', 'u2t'] };
export const ITEMS = [ /* عناصر الوحدة بالترتيب */ ];
export const NAFES = [ /* نصوص وأسئلة نافس */ ];
export const FAHM = [ /* نصوص فهم المقروء من موضوعات الدروس — نفس شكل NAFES */ ];
export const BOT = [ /* [[كلمات مفتاحية], 'إجابة'] للمساعد */ ];
```

## العنصر (ITEM) = درس أو مدخل وحدة أو اختبار
```js
{ id: 'u2d1', kind: 'lesson' | 'entry' | 'test', badge: '١' /* رقم أو رمز */,
  t: 'الدرس الأول: الرياضُ والملكُ الشجاع', s: 'ربوعٌ من بلادي · ص ٦٢–٧١', p: [62, 71],
  tabs: [['read','📖','النصّ'], ['comp','💡','الفهم'], ..., ['games','🎮','ألعاب']],
  blocks: { read: [ ...كتل ], comp: [ ... ], ... },   // مفتاح لكل تبويب (عدا games وnafes)
  gq: [[سؤال, [خيارات], رقم_الصحيح]] }                  // اختياري: أسئلة إضافية للألعاب
```
- تبويب `games` يُولَّد تلقائيًا من كتل mcq/tf/blank/match/cards/sort. ضعه آخر كل درس.
- تبويب `nafes` (بلا كتل) يعرض تدريبات نافس للوحدة؛ ضعه في عنصر الاختبار (kind:'test') قبل games.
- الصفحات أرقام الكتاب المطبوعة (= أرقام صفحات الـPDF).
- تبويب `fahm` (بلا كتل) يعرض نصوص فهم المقروء للقسم؛ تبويب `nafes` يعرض نافس للقسم.

## أنواع الكتل (block.type)
كل كتلة تقبل `h` (عنوان) و`page` (رقم صفحة الكتاب، يظهر زر يفتح صورتها).
| type | الحقول |
|---|---|
| `text` | `html` نص/HTML حرّ (تعليمات، شرح قاعدة، صندوق «أتعلم») |
| `read` | `text: { title, page, paras: [[متحدث, 'نص الفقرة بتشكيله', صفحة]], spk?: { n:['الراوي','#5a6270'], a:['خالد','#c0571a'] }, roles?: true, note?, src? }` — `n` الراوي. `roles:true` يفعّل القراءة بالأدوار. المفردة الجديدة تكتب `[[الكلمة|معناها]]` |
| `poem` | `title, page, lines: [['الشطر الأول','الشطر الثاني'], ...], src?` — للأناشيد |
| `mcq` | `items: [[سؤال, [خيارات], رقم_الصحيح(من 0), شرح?, صفحة?]]` ، `box?:1` لشكل مربع ✓ |
| `tf` | `items: [[عبارة, true/false, شرح?]]` |
| `open` | `items: [[سؤال, إجابة نموذجية]]`, `oral?:1` للأسئلة الشفهية, `intro?` HTML قبل الأسئلة, `nums?` ترقيم مخصص |
| `match` | `left:[...]`, `right:[...]` (نفس الطول، المتقابلان صحيحان), `extra?:'خيار زائد'`, `hint?`, `gq?` صياغة سؤال اللعبة مثل 'مَعْنَى' |
| `sort` | `bins:['سلة ١','سلة ٢']`, `items:[[كلمة, رقم_السلة, سبب?]]`, `hint?`, `gq?` |
| `order` | `items:[[ [كلمات مبعثرة], 'الجملة الصحيحة' أو ['ترتيب١','ترتيب٢'] ]]` |
| `seq` | `items:['الحدث الأول', 'الثاني', ...]` بالترتيب الصحيح (تُخلط تلقائيًا) |
| `blank` | `items:[[ما قبل الفراغ, ما بعده, الإجابة, [خيارات تشمل الإجابة]]]`, أو `bank:[...]` مشترك بدل الخيارات |
| `dict` | `mode:'copy'|'seen'|'test'`, `items:['جملة بتشكيلها', ...]` — منسوخ/منظور/اختباري (يمليه الجهاز) |
| `khat` | `text:'النص بالشكل'`, `note?` — لوحة كتابة بالإصبع بسطور الخط |
| `cards` | `items:[[كلمة, معنى]]` بطاقات تقلب |
| `write` | `prompt` HTML, `ideas?:[...]` أفكار تُضاف بالنقر, `model?` نموذج مقترح, `ph?` |
| `check` | `items:['بند ...']` قائمة تقويم ذاتي محفوظة |
| `parts` | `cats:['كان وأخواتها','اسم كان','خبر كان']`, `items:[[ [كلمات الجملة], [رقم الفئة لكل كلمة أو -1] ]]` — تلوين أركان الجملة (النحو) |
| `page` | `page`, `note?` — يعرض صورة صفحة الكتاب (لنشاط لا يُحوَّل لتفاعلي: رسم، جدول كبير...) |

## نافس (NAFES)
مصفوفة نصوص؛ كل نص:
```js
{ title: 'عنوان', kind: 'نصٌّ أدبيّ' | 'نصٌّ معلوماتيّ', paras: ['فقرة', 'فقرة'], src?: '',
  qs: [[سؤال, [أ, ب, ج, د], رقم_الصحيح, 'شرح الإجابة', 'المهارة']] }
```
المهارات (اختر منها حرفيًا): `معنى المفردة` · `استرجاع معلومة` · `استنتاج` · `الفكرة الرئيسة` · `ترتيب الأحداث` · `السبب والنتيجة` · `التحليل` · `الحكم والتقويم` · `الظاهرة اللغوية` · `الإملاء`.

## قواعد إلزامية
- النصوص المنقولة من الكتاب (النص القرائي، النشيد، نصوص الاختبار، جمل الإملاء، أمثلة القواعد) **بتشكيلها حرفيًا كما في صورة الصفحة**. لا تكتب من الذاكرة.
- الآيات والأحاديث كما في الكتاب حرفيًا.
- الأسئلة والتعليمات بصياغة الكتاب. الإجابات النموذجية التي لا يذكرها الكتاب من صياغتك، مختصرة وصحيحة.
- كل نشاط في الكتاب يتحول لتفاعلي إن أمكن؛ ما لا يمكن (رسم، تلوين، مشروع) → كتلة `text` بتعليمته + `page`، أو `write`.
- نصوص الاستماع (نص الاستماع في مدخل الوحدة) لا تظهر غالبًا في كتاب الطالب؛ انقل ما في الصفحات فقط (الأسئلة والصور). لا تخترع نص الاستماع.
- نافس: ٣ نصوص لكل وحدة (أدبي + معلوماتي + أدبي/معلوماتي)، كل نص ٨٠–١٥٠ كلمة، مضبوط بالشكل ضبطًا كاملًا أو شبه كامل، مناسب لطالب الثالث، **من تأليفك** في موضوع الوحدة، ولكل نص ٥–٦ أسئلة بأربعة خيارات متقاربة الطول، الصحيح موزّع على المواقع، وشرح قصير.
- استخدم الأرقام العربية الهندية (١٢٣) في النصوص المعروضة.
- علامات الاقتباس في JS: استخدم '...' وتجنّب ' داخل النص (لا يوجد في العربية عادةً).
